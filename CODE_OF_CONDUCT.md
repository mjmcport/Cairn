# Code of Conduct

Cairn adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Its full text applies to every project space: issues, pull requests, discussions and any other channel the project uses.

## In short

- Be respectful and assume good intent.
- Give and accept feedback about the work, not the person.
- Harassment, insults, sexualized language or imagery, and publishing someone's private information are not acceptable.

## Reporting

Report a problem privately to the maintainer, [@mjmcport](https://github.com/mjmcport), through the contact details on that GitHub profile. Reports are kept confidential.

## Enforcement

The maintainer reviews every report and may respond with a correction, a warning, a temporary ban or a permanent ban, following the Contributor Covenant's enforcement guidelines.
